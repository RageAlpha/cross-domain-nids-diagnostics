# Code availability release text

Do not claim an external repository until its anonymous URL is live and can be
opened without an author-linked account.

## Anonymous-review version

> The finalized reproduction code, frozen protocols, fixed split maps, compact
> reference results, and figure inputs are available in an anonymous
> reviewer-accessible repository at [ANONYMOUS URL], release
> `v1.0.0-manuscript`, commit [COMMIT SHA]. Raw NF-UQ-NIDS-v3 datasets are not
> redistributed and must be downloaded from the University of Queensland NIDS
> dataset page under the provider's terms.

## Accepted/public version

Replace the anonymous authors and URL with the final public repository,
software citation, permanent archive URL or DOI, release tag, and commit SHA.
Do not invent a DOI. Update `CITATION.cff` in the same release.

Publishing from a personal GitHub account can defeat double anonymity through
the username, profile, historical repositories, commit emails, personal
website, or account search results. Prefer an anonymous review link or an
independent anonymous account during review.
